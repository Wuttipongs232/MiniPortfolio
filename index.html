วุฒิพงษ์ แซ่เจียม (นิค)

สาขาวิชาวิศวกรรมซอฟต์แวร์ (หมู่เรียน 68/51) มหาวิทยาลัยราชภัฏนครปฐม

นักศึกษาวิศวกรรมซอฟต์แวร์ที่มีความมุ่งมั่นในการเรียนรู้และพัฒนาเว็บแอปพลิเคชันอย่างเป็นระบบ มีความสนใจเป็นพิเศษในการเขียนโปรแกรมสร้างเว็บไซต์ทั้งส่วน Front-End และ Back-End รวมถึงการจัดการระบบฐานข้อมูล SQL การนำ Semantic HTML และ Responsive CSS มาใช้ออกแบบโครงสร้างเว็บที่ใช้งานง่าย

ดูผลงาน ติดต่อพูดคุย

แนวคิดและเป้าหมายในการพัฒนาเว็บไซต์

เน้นการออกแบบเว็บไซต์ที่คำนึงถึงประสบการณ์ผู้ใช้งาน (User Experience) โครงสร้างโค้ดที่เป็นระเบียบ อ่านและดูแลรักษาง่าย (Clean Code) พร้อมทั้งเรียนรู้และประยุกต์ใช้เครื่องมือ modern web development เพื่อสร้างสรรค์เว็บแอปพลิเคชันที่มีประสิทธิภาพ มีความปลอดภัย และรองรับการแสดงผลทุกอุปกรณ์
