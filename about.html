ประวัติและการศึกษา

ชื่อ-นามสกุล: นายวุฒิพงษ์ แซ่เจียม (นิค)

การศึกษาปัจจุบัน: ปริญญาตรี สาขาวิชาวิศวกรรมซอฟต์แวร์ (หมู่เรียน 68/51) มหาวิทยาลัยราชภัฏนครปฐม

เป้าหมาย: ก้าวสู่นักพัฒนาเว็บมืออาชีพ (Full-Stack Web Developer) ที่มีความเชี่ยวชาญในการออกแบบ พัฒนา และดูแลรักษาระบบเว็บแอปพลิเคชันที่มีประสิทธิภาพสูง

ความสนใจและการเรียนรู้

มีความสนใจเป็นพิเศษด้านการพัฒนาเว็บแอปพลิเคชัน (Web Development) ทั้งส่วนหน้าเว็บ (Front-End) และระบบหลังบ้าน (Back-End) โดยปัจจุบันกำลังมุ่งเน้นศึกษาและฝึกฝนภาษา JavaScript เพื่อเพิ่มปฏิสัมพันธ์ให้กับเว็บไซต์ เรียนรู้หลักการเขียนโค้ดที่เป็นระเบียบ (Clean Code) ตลอดจนศึกษาสถาปัตยกรรมซอฟต์แวร์และการจัดการระบบฐานข้อมูลอย่างต่อเนื่อง

ทักษะทางเทคนิค (Technical Skills)

  • HTML5 / CSS3
  • JavaScript
  • PHP / MySQL
  • Git / GitHub

ประสบการณ์และกิจกรรม

  • พัฒนาเว็บแอปพลิเคชันและฐานข้อมูลแบบ CRUD ในรายวิชาการเขียนโปรแกรมบนเว็บ
  • ออกแบบ Use Case Diagram และวางสกีมาฐานข้อมูล (Database Schema) ระบบ Board Game Cafe Management
  • วางแผนและจัดทำโครงการจิตอาสาพัฒนาอุปกรณ์และสาธารณประโยชน์ภายในมหาวิทยาลัยราชภัฏนครปฐม
